# Pokyny externému auditorovi — EA-011

**Autor teórie:** Martin Jambor  
**Tvorca auditovaných skriptov:** Codex (OpenAI)

Over manifest a runtime mapu. V čerstvej kópii `REPRO/` spusť iba runner
305 podľa dokumentu 03. Runneri 301–303 sú `DO_NOT_RUN_AUDIT_TECHNICAL` a
KMPC-060 je iba už vykonaná read-only diagnóza. Nemeň support, M1 depth,
prahy, plochy, vstupy ani runtime limit.

Zapíš presný príkaz, exit code, wall time, SHA-256 generated JSON a celé
prostredie. Over source/prerequisite guard, dve odlišné support množiny,
owner restore, M1, accepted/audit rank/core/holdout, S-C0, common, tail a
background. Osobitne potvrď, že automatické C2 poradie po REVIEW nepokračuje.

Každá odchýlka je `DECLARED_DEVIATION` bez official T2 statusu. Externý
audit nemení projektový verdict ani skóre.
