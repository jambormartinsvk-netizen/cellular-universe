# Pokyny externému auditorovi EA-043

1. Pracujte iba s týmto balíkom a auditujte iba otázky a T1 hranicu z
   dokumentu 00.
2. Najprv načítajte izolovaný ruleset `EVIDENCE/011` až `015` a overte jeho
   exact hashe voči charteru.
3. Z koreňa projektu spustite R6 package preflight cez PowerShell 7+ a
   zapíšte presný príkaz, exit code a wall time.
4. Overte manifest `15/15`, source/copy paritu, package `22`, response `1`,
   `REPRO=0`, runtime rows `0`, nulové duplicity a dočasné súbory.
5. Nevykonávajte Python, solver, search ani download dát. Balík nemá runtime,
   official vetvu ani generated JSON.
6. Auditujte B6b-1 common/family moment inequalities, rovnakú hĺbku MF1–MF4
   a hranicu non-overclaim.
7. Auditujte B6b-2 kovariantné `P0–P8`, znamienka, source-off limity a
   rodinné linear-response identity.
8. Auditujte immutable search/coverage/no-mutation/ranking guardy a zákaz
   quasi-holdout leakage.
9. Oddeľte E3 outer interval od E2 flat-LambdaCDM mapovania, kalibráciu od
   comparatora a DESI quasi-holdout od ranking vstupu.
10. DES/KiDS/HSC hodnoty tagujte `INFERRED_FROM_PROJECT_DOCS`; balík
    neposkytuje podklad na nezávislé overenie survey publikácií alebo
    likelihoodov.
11. Auditujte split stavu a minimalitu neexekvovateľného successor balíka
    `D04+D08+D10` pri zachovaní D03/D05–D09/D11.
12. Každý hlavný záver označte dôkazovým tagom a osobitne uveďte dopad na
    package tier a fyzikálny verdict.
13. Každú odchýlku zapíšte explicitne; z T1 balíka nevydávajte computed ani
    observačný verdict.

Povinné ledger termíny: `generated JSON`, `exit code`, `wall time`,
`odchýlka`.
