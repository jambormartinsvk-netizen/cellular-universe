The Cellular Universe is a cosmological model in which space is a random causal network of Planck-scale cells whose metabolism — digestion of vacuum "fuel" and cell division — generates expansion, matter, and dark-sector phenomenology. This record registers the model's falsifiable predictions prior to upcoming measurements. The model contains one fitted parameter (λ = 0.10–0.15); δ = 1/(⟨k⟩ + gB) = 1/(15.54 + 28) = 0.0230 and ΔNeff = 0.0535 are derived from the Poisson–Voronoi network constant and the Standard Model boson count.

How the model can die (registered kill conditions)

Detection of primordial B-modes (r ≥ 10−3) • a confirmed non-gravitational dark-matter interaction • S8 ≤ 0.78 together with wa ≤ −0.6 • local H0 ≥ 72 with systematics fully accounted for • discovery of a new fundamental carrier boson (changes gB = 28) • CMB-S4: ns outside 0.9656 ± 0.004.

Internal consistency (computed, reproducible)

Newtonian gravity emerges on the network (R² = 0.999, two independent couplings); the linear Lorentz-violating dispersion term vanishes exactly (parity), with residual violations suppressed as (lP/λ)² ~ 10−58 — 38 orders below current tests; one speed of light for all fields is enforced by GW170817 to 4×10−15 and satisfied by the capacity-identity of the network. Data state at registration: DESI DR2 (w0 = −0.75 ± 0.06, wa = −0.86 ± 0.25; survey mapping completed April 2026, final analysis pending); KiDS-Legacy S8 = 0.815 (+0.016/−0.021); Planck ns = 0.9649 ± 0.0042.

Methods note

Calculations and adversarial review were performed in collaboration with an AI system (Claude, Anthropic) under the author's direction, using a pre-registered falsification protocol (20 dead branches, 9 documented methodological pitfalls, zero reversals over the whole project). The derivations of δ and ns were additionally cross-checked by a second, independent AI system; this constitutes a consistency check, not peer review. Independent human replication of the pipelines is explicitly invited — the README lists the validation values every run must reproduce before its outputs can be trusted.
