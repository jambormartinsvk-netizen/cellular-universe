# A2-K1 — base závislosti

Žiadny aktívny zdieľaný base modul. Rovnice sú zmrazené v historických
runneroch 22–24. Keďže koľaj je fyzikálne mŕtva vo svojom presnom rozsahu,
extrahovanie do nového jadra by neprinieslo vedeckú hodnotu. Nový mechanizmus
musí dostať nové číslo koľaje a vlastný base kontrakt.
