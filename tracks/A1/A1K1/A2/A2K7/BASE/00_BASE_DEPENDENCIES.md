# A2-K7 — base závislosti

Žiadny autoritatívny zdieľaný fyzikálny modul. Historické runnery 50 a
55–62 sú sondy rozdielnych mikrofyzických možností, nie spoločná uzavretá
RHS. Ak vznikne explicitný pozitívny collision/mediator kernel, jeho rovnice
sa najprv zapíšu do jedného nového verziovaného base modulu a tenké runnery
budú meniť iba parametre a brány.
